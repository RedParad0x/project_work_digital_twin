# Media Digital Twin

Media Digital Twin è una piattaforma di intelligence che monitora segnali finanziari, social e mediatici relativi a un insieme di aziende.

## Feature

- ingestion multi-source
- MongoDB data lake
- Neo4j knowledge graph
- NLP sentiment analysis
- dashboard aziende
- confronto MongoDB vs Neo4j
- controllo pipeline

## Perché MongoDB + Neo4j

MongoDB gestisce volume e flessibilità.  
Neo4j gestisce relazioni e traversal.  
Insieme forniscono due viste complementari dello stesso Digital Twin.
